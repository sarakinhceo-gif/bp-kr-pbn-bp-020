## 1. 화면 뒤로 숨겨진 원본과 차이점
"화면 안에는 단순한 텍스트가 아니었다."
실제로 USB 내부에 담긴 파일은 뉴스가 보도한 것보다 훨씬 더 많은 메타데이터를 포함하고 있었다. 언론이 공개한 것은 최종 편집된 버전이고, 원본에는 수집 시간대별 로깅 정보가 그대로 남아있어 추적이 가능했다. 이 차이는 데이터 가공 과정에서 손실이 발생한 결과를 보여준다.

## 2. 성남 프로그램 개발 마케팅에서의 함의
소프트웨어 개발이나 마케팅 프로세스에서 원본 로그를 어떻게 정리하느냐가 신뢰도에 직결된다. 성남 프로그램을 예로 들면, 초기 테스트 데이터를 클라이언트에게 넘길 때 불필요한 세부 정보를 제거하는 단계가 필수적이다. 하지만 너무 과하게 다듬으면 실제 동작 환경의 오류나 패턴이 감춰지는 경우가 발생한다.
